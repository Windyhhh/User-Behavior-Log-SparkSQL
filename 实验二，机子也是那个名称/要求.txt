Hadoop/Spark大数据开发训练 - 实验二
一、实验目标
1.认识 Spark SQL 与 DataFrame 的基本概念与核心特性，理解其在 Spark 生态体系中的作用，掌握通过 Spark SQL 和 DataFrame 对结构化与半结构化数据进行查询和分析的基本方法。
2.掌握 Spark SQL 中基于函数式 API和基于 SQL 语句两种数据处理方式，理解二者的使用场景与差异，能够灵活选择合适的方法对数据进行查询、统计与分析，从而高效完成实际数据分析任务并解决具体业务问题。
二、实验环境与工具
1.系统与集群：已搭建完成的 Spark2.2.3 集群。
2.开发与连接工具：虚拟机搭建工具（VMWare等），SSH工具（Xshell 7等），文件传输工具（Xftp等），IDEA等
3.网络与浏览器：集群节点网络互通，Windows 端浏览器（Chrome/Firefox）可访问集群 Web 端口。
三、实验要求
1.确认 Hadoop 与Spark 进程正常运行，使用Spark shell本地或集群模式编程； 
2.所有操作需记录完整命令（含参数）、执行结果（文字描述或截图），Web 界面验证需包含地址栏 URL 与关键页面内容；
3.从 HDFS 分布式文件系统中读取数据源，完成数据的处理与分析，并将最终计算结果规范地输出并存储到 HDFS 中；
4.从程序运行参数中动态获取输入输出路径，输出路径中需要明确体现每位同学姓名对应的拼音；
